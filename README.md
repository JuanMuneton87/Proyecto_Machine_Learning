# Predicción de precios de viviendas mediante técnicas de Machine Learning

## Descripción del proyecto

Proyecto académico del curso de Modelos y Simulación de Sistemas II orientado a la predicción de precios de viviendas mediante técnicas de Machine Learning, utilizando el conjunto de datos asociado a la competencia [House Prices - Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/overview) de Kaggle.

El objetivo es estudiar el problema de regresión, analizar los datos y comparar diferentes modelos de aprendizaje automático, aplicando los conceptos de entrenamiento, validación, evaluación y reducción de dimensionalidad.

## Estado del proyecto

**Primera entrega de avance:** descripción del problema y estado del arte.
